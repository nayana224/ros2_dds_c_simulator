# 02. 자료구조 설계

## 1. 연결 리스트

### 사용 위치
- Node 목록
- Topic 목록
- Publisher 목록
- Subscriber 목록

### 선택 이유
등록되는 Node와 Topic의 개수가 실행 중 동적으로 변할 수 있으므로, 삽입과 삭제가 유연한 연결 리스트를 사용한다.

## 2. 큐

### 사용 위치
- Topic별 Message Buffer

### 선택 이유
일반적인 메시지 처리 순서는 먼저 발행된 메시지를 먼저 처리하는 FIFO 구조이므로 큐를 사용한다.

## 3. 우선순위 큐

### 사용 위치
- QoS priority mode의 Message Buffer

### 선택 이유
긴급 정지 메시지처럼 일반 메시지보다 먼저 처리되어야 하는 메시지를 표현하기 위해 priority 값을 기준으로 메시지를 정렬한다.

## 4. 그래프

### 사용 위치
- Node 간 통신 관계 표현

### 선택 이유
ROS2 시스템은 Node와 Topic 간 연결 관계로 이루어진 그래프 구조이다. 특정 Node에서 다른 Node까지 메시지가 전달 가능한지 탐색하기 위해 그래프와 BFS를 사용한다.
