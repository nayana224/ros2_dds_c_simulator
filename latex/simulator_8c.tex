\doxysubsection{Detailed Description}
ROS2 Pub/\+Sub C Simulator의 핵심 자료구조 구현. 

\doxylink{struct_node}{Node}, \doxylink{struct_topic}{Topic}, \doxylink{struct_publisher}{Publisher}, Subscriber는 단일 연결 리스트로 관리한다. Message는 \doxylink{struct_topic}{Topic} 내부 priority queue에 저장하며, publish/subscribe 관계는 그래프 간선처럼 해석하여 출력과 BFS 경로 탐색에 사용한다.
