ROS2의 Pub/\+Sub와 DDS 메시지 전달 개념을 실제 ROS2 라이브러리 없이 C언어 자료구조로 단순화한 시뮬레이터입니다.

이 프로젝트는 자료구조 수업 최종 프로젝트를 목표로 하며, \doxylink{struct_node}{Node}, \doxylink{struct_topic}{Topic}, \doxylink{struct_publisher}{Publisher}, \doxylink{struct_subscriber}{Subscriber}, \doxylink{struct_message}{Message} Queue, Priority Queue, Communication Graph, BFS Path Search를 직접 구현합니다.\hypertarget{md__r_e_a_d_m_e_autotoc_md72}{}\doxysection{\texorpdfstring{주요 특징}{주요 특징}}\label{md__r_e_a_d_m_e_autotoc_md72}

\begin{DoxyItemize}
\item 실제 ROS2, DDS, RTPS, socket, 외부 네트워크 라이브러리를 사용하지 않습니다.
\item 모든 통신 관계는 하나의 로컬 C 프로그램 안에서 시뮬레이션합니다.
\item \doxylink{struct_node}{Node}, \doxylink{struct_topic}{Topic}, \doxylink{struct_publisher}{Publisher}, Subscriber는 연결 리스트로 관리합니다.
\item Message는 \doxylink{struct_topic}{Topic} 내부 priority queue에 저장합니다.
\item priority가 높은 Message가 먼저 수신됩니다.
\item priority가 같은 Message는 발행 순서를 유지합니다.
\item Communication Graph를 출력할 수 있습니다.
\item \doxylink{struct_node}{Node} 간 메시지 전달 가능 경로를 BFS로 탐색할 수 있습니다.
\item CLI는 ROS2 명령어 스타일을 참고한 명령어 기반 인터페이스입니다.
\end{DoxyItemize}\hypertarget{md__r_e_a_d_m_e_autotoc_md73}{}\doxysection{\texorpdfstring{프로젝트 구조}{프로젝트 구조}}\label{md__r_e_a_d_m_e_autotoc_md73}

\begin{DoxyItemize}
\item 실제 ROS2 Node나 DDS middleware와 통신하지 않습니다.
\item 여러 프로세스 간 통신을 수행하지 않습니다.
\item 모든 상태는 프로그램 실행 중 메모리에만 저장됩니다.
\item 프로그램 종료 시 등록 정보와 메시지는 사라집니다. 
\end{DoxyItemize}
