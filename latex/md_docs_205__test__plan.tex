이 문서는 ROS2 DDS C Simulator의 기능 요구사항 FR-\/01부터 FR-\/10까지를 검증하기 위한 테스트 시나리오를 정리한다.

테스트는 두 가지 방식으로 수행한다.


\begin{DoxyItemize}
\item 자동 테스트\+: {\ttfamily mingw32-\/make test}
\item 수동 CLI 테스트\+: {\ttfamily mingw32-\/make run} 실행 후 명령어 입력
