Implement a C-\/based simulator that mimics ROS2-\/style Pub/\+Sub communication using data structures.\hypertarget{md__a_g_e_n_t_s_autotoc_md2}{}\doxysection{\texorpdfstring{Important Constraints}{Important Constraints}}\label{md__a_g_e_n_t_s_autotoc_md2}

\begin{DoxyItemize}
\item Use C language only.
\item Do not use actual ROS2 libraries.
\item Do not use DDS, RTPS, sockets, or external networking libraries.
\item The simulator must run locally on a single laptop.
\item Focus on data structures\+: linked list, queue, priority queue, graph.
\item Keep the code simple enough for a data structure course final project.
\item Every major function must have comments explaining the data structure operation.
\end{DoxyItemize}\hypertarget{md__a_g_e_n_t_s_autotoc_md3}{}\doxysection{\texorpdfstring{Build}{Build}}\label{md__a_g_e_n_t_s_autotoc_md3}
